# Pendant Companion v0.14.x "zero setup" - plan of record (from the user, 10 Nov 2026 ~5:40pm AEDT)
One goal: new user installs, taps ONE button, wears the pendant, gets a Day recap card after one day, no settings work.
## Test
1. Open app, tap one button, accept BT + notifications prompts, paired <30s. 2. Land on Home in plain words, no model/folder/key/mic/hour choices. 3. "Today so far: N conversations" within minutes of first sync. 4. Day recap at 9pm or first open after, no key. 5. Optional "Make it smarter" one-tap Gemini key paste.

## Locked
Privacy-first on-device; non-destructive sync; BYO-key only; no analytics/accounts; network only model downloads + user AI provider. Never rename prefs/files (setup_done, drive_tree_uri, speaker_enroll_version, enroll.bin, vec_-1.bin, session naming, request code 9402). Data survives upgrades; first-run screen once. Debug-signed APK <~20MB, arm64-v8a, single module, no new dependencies (no WorkManager/ML runtime/Drive SDK). Flagged decisions NOT to build without the user: hosted AI insights; bundled on-device LLM.
## Working rules
No device access during development; the user sideloads each APK and reports. Bump version every build. Read reports against status trail before changing code. Never break data flow. UI voice: plain warm second person.
